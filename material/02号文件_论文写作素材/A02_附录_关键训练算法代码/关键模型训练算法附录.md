# 附录 A　CatBoost 折外（OOF）训练主循环

## A.1 算法说明

**目的：**在 develop 集上得到无偏的折外预测概率，用于模型比较与融合权重选择，避免“用验证集调参后再报告同一验证集成绩”所产生的乐观偏差。

流程：

1. 将 develop 划分为 $K$ 折，并保持各类别比例基本一致；
2. 对第 $k$ 折，仅在其余 $K-1$ 折上拟合预处理器和 CatBoost，在第 $k$ 折上预测；
3. 将全部验证折预测拼接成完整 OOF 概率矩阵，再在 OOF 上搜索融合权重或分类阈值；
4. 最终模型在全部 develop 上重训，仅在冻结的 `final_validation` 上报告一次结果。

任务一损失函数为 `MultiClass`（Low/Medium/High），任务三损失函数为 `Logloss`（0/1）。折内预处理只在训练折上 `fit`，验证折仅执行 `transform`，以避免数据泄漏。

```python
    oof_pred = np.empty(n, dtype=object)

        X_tr = transform_cat(X_pos.iloc[tr], state)
        X_va = transform_cat(X_pos.iloc[va], state)

        p.setdefault("loss_function", "MultiClass")
        p.setdefault("eval_metric", "MultiClass")

        model = CatBoostClassifier(**p)
        model.fit(
            X_tr,
            y_pos.iloc[tr],
            cat_features=cat_indices(state),
            eval_set=(X_va, y_pos.iloc[va]),
            early_stopping_rounds=50,
            use_best_model=True,
        )

        proba = model.predict_proba(X_va)  # 对齐为 [Low, Medium, High]
        pred = pred_from_proba(proba)

        oof_pred[va] = pred
```

# 附录 B　有序三分类：双累积边界概率分解

## B.1 算法说明

任务一的标签满足有序关系：

$$
\text{Low}<\text{Medium}<\text{High}.
$$

因此，不宜完全按照无序三分类处理。定义两个累积事件：

$$
A=\{Y\ge \text{Medium}\},
\qquad
B=\{Y=\text{High}\}.
$$

分别训练两个二分类器，得到：

$$
p_A(x)=\Pr(A\mid x),
\qquad
p_B(x)=\Pr(B\mid x).
$$

由于事件 $B$ 是事件 $A$ 的子集，应满足：

$$
p_B(x)\le p_A(x).
$$

在强制单调约束后，三类概率还原为：

$$
\begin{aligned}
\Pr(Y=\text{Low}\mid x)
&=1-p_A(x),\\
\Pr(Y=\text{Medium}\mid x)
&=p_A(x)-p_B(x),\\
\Pr(Y=\text{High}\mid x)
&=p_B(x).
\end{aligned}
$$

其中：

- M2：两个累积边界均使用 CatBoost 二分类器；
- M6：两个累积边界均使用标准化后的 LogisticRegression，以获得可解释的线性有序结构。

## B.2 代码

源文件：`src/tasks/task1/ordinal.py`

```python
def _binary_labels(y):
    """构造两个累积二分类标签。"""
    y_n = normalize_label_array(y)

    ge_med = np.array(
        [0 if lab == "Low" else 1 for lab in y_n],
        dtype=int,
    )  # Y >= Medium

    ge_high = np.array(
        [1 if lab == "High" else 0 for lab in y_n],
        dtype=int,
    )  # Y == High

    return ge_med, ge_high


def ordinal_probs_from_boundaries(p_ge_med, p_ge_high):
    """由累积概率还原 (Low, Medium, High)。"""
    p_ge_high = np.minimum(p_ge_high, p_ge_med)

    p_low = 1.0 - p_ge_med
    p_med = p_ge_med - p_ge_high
    p_high = p_ge_high

    p = np.column_stack([p_low, p_med, p_high])
    p = np.clip(p, 0.0, None)

    s = p.sum(axis=1, keepdims=True)
    s[s <= 0] = 1.0

    return p / s
```

# 附录 C　有序回归与温度 Softmax 软概率（M3）

## C.1 算法说明

将有序类别映射为数值：

$$
\text{Low}\mapsto 0,
\qquad
\text{Medium}\mapsto 1,
\qquad
\text{High}\mapsto 2.
$$

使用 CatBoostRegressor 拟合连续得分 $\hat{s}(x)$。为了与分类概率进行融合，将连续预测值转换为三类软概率：

$$
\Pr(Y=k\mid x)
=
\frac{
\exp\!\left(-\dfrac{|\hat{s}(x)-c_k|}{T}\right)
}{
\displaystyle
\sum_{j=0}^{2}
\exp\!\left(-\dfrac{|\hat{s}(x)-c_j|}{T}\right)
},
\qquad
c=(0,1,2).
$$

其中，$T>0$ 为温度参数。$T$ 越小，概率分布越尖锐；$T$ 越大，概率分布越平滑。本项目最终锁定的温度约为：

$$
T\approx 0.5.
$$

## C.2 代码

源文件：`src/tasks/task1/regression.py`

```python
def score_to_soft_proba(score, temperature):
    """连续有序得分转换为三类软概率。"""
    centers = np.array([0.0, 1.0, 2.0])

    logits = (
        -np.abs(
            score.reshape(-1, 1)
            - centers.reshape(1, -1)
        )
        / max(temperature, 1e-6)
    )

    logits = logits - logits.max(axis=1, keepdims=True)
    exp_values = np.exp(logits)

    return exp_values / exp_values.sum(axis=1, keepdims=True)


y_ord = y.map(
    {
        "Low": 0,
        "Medium": 1,
        "High": 2,
    }
).astype(float)

model.fit(
    X_tr,
    y_ord[tr],
    cat_features=cat_idx,

    model.predict(X_va),
```

# 附录 D　Soft Vote：异构概率加权融合

## D.1 算法说明

设候选模型集合为：

$$
\left\{
P^{(m)}(x)
\right\}_{m=1}^{M},
\qquad
P^{(m)}(x)\in\Delta^2.
$$

融合权重满足：

$$
w_m\ge 0,
\qquad
\sum_{m=1}^{M}w_m=1.
$$

通过步长 $\delta=0.05$ 的网格搜索，在 OOF 上最大化 Accuracy。融合概率为：

$$
\widehat{P}(x)
=
\sum_{m=1}^{M}
w_mP^{(m)}(x).
$$

最终类别预测为：

$$
\widehat{y}
=
\arg\max_{k\in\{0,1,2\}}
\widehat{P}_k(x).
$$

本项目锁定权重为：

$$
w_{\mathrm{M6}}=0.55,
\qquad
w_{\mathrm{M1}}=0.35,
\qquad
w_{\mathrm{M3}}=0.10.
$$

对应最终验证准确率约为：

$$
\mathrm{Accuracy}=0.8607.
$$

## D.2 代码

源文件：`src/tasks/task1/ensemble.py`

```python
def _iter_simplex(m, step):
    """生成 m 维非负权重且权重和为 1 的网格点。"""
    grid = np.round(
        np.arange(0.0, 1.0 + 1e-12, step),
        10,
    )

    if m == 1:
        yield (1.0,)
        return

    for weights in itertools.product(grid, repeat=m - 1):
        s = float(sum(weights))

        if s > 1.0 + 1e-8:
            continue

        last = round(1.0 - s, 10)

        if last < -1e-8:
            continue

        yield tuple(float(w) for w in weights) + (float(last),)


def soft_vote_search(models, y, max_models=4, step=0.05):
    """models: {name: proba(n, 3)}；在 OOF 上搜索最优权重。"""
    y_n = normalize_label_array(y)

    y_idx = np.array(
        [
            {
                "Low": 0,
                "Medium": 1,
                "High": 2,
            }[lab]
            for lab in y_n
        ]
    )

    ranked = sorted(
        models.items(),
        key=lambda kv: float(
            (
                pred_from_proba(kv[1])
                == y_n
            ).mean()
        ),
        reverse=True,
    )[:max_models]

    names = [name for name, _ in ranked]
    probs = [prob for _, prob in ranked]

    best = None
    best_p = None

    for weights in _iter_simplex(len(names), step):
        p = sum(
            w * prob
            for w, prob in zip(weights, probs)
            if w
        )

        acc = float(
            (
                np.argmax(p, axis=1)
                == y_idx
            ).mean()
        )

        n_active = int(
            sum(w > 1e-12 for w in weights)
        )

        if (
            best is None
            or acc > best["accuracy"] + 1e-12
            or (
                abs(acc - best["accuracy"]) <= 1e-12
                and n_active < best.get("_n_active", 99)
            )
        ):
            best = {
                "accuracy": acc,
                "weights": dict(zip(names, weights)),
                "_n_active": n_active,
            }
            best_p = p

    return best, best_p
```

# 附录 E　多数类分类器与弱信号锁定（任务二）

## E.1 算法说明

在 $0$-$1$ 损失下，若条件分布中不存在稳定、可靠的可分信号，则 Bayes 最优决策退化为预测先验众数：

$$
\widehat{y}(x)
\equiv
c^\star,
\qquad
c^\star
=
\arg\max_{c\in\{0,1\}}
\Pr(Y=c).
$$

弱信号锁定规则为：

$$
\max_j
\left(
\mathrm{Accuracy}_j
-
\mathrm{Accuracy}_{\mathrm{majority}}
\right)
\le \varepsilon,
$$

或

$$
\max_j
\left|
\mathrm{AUC}_j-0.5
\right|
<
\eta.
$$

其中，$\varepsilon$ 为最低有效准确率增益阈值，$\eta$ 为弱信号 AUC 阈值。本项目示例设置为：

$$
\varepsilon=0.0005,
\qquad
\eta=0.02.
$$

若任一弱信号条件成立，则锁定多数类策略。

```python
def lock_final_scheme(
    comparison,
    majority_acc,
    max_auc_gap=0.02,
    tie_eps=0.0005,
):
    non_m = comparison[
        comparison["candidate"] != "M_majority"
    ]

    best_model_acc = float(
        non_m["accuracy"].max()
    )

    max_auc_dev = float(
        non_m["auc_gap_from_0_5"].max()
    )

    weak_no_lift = (
        best_model_acc
        <= majority_acc + tie_eps
    )

    weak_auc = (
        max_auc_dev < max_auc_gap
    )

    if weak_no_lift or weak_auc:
        locked = "M"
        reason = []

        if weak_no_lift:
            reason.append(
                f"no Acc lift > {tie_eps} over majority"
            )

        if weak_auc:
            reason.append(
                f"max |AUC-0.5|="
                f"{max_auc_dev:.4f} "
                f"< {max_auc_gap}"
            )
    else:
        locked = (
            non_m
            .sort_values(
                "accuracy",
                ascending=False,
            )
            .iloc[0]["candidate"]
        )

        reason = [
            "best OOF accuracy among non-majority candidates"
        ]

    return {
        "locked_scheme": locked,
        "lock_reason": "; ".join(reason),
    }
```

# 附录 F　二分类 Soft Blend 融合（任务三）

## F.1 算法说明

任务三主模型输出正类概率 $p_1^{(m)}(x)$。多个概率源采用非负权重凸组合：

$$
p_{\mathrm{soft}}(x)
=
\sum_{m=1}^{M}
w_m p_1^{(m)}(x).
$$

其中：

$$
w_m\ge 0,
\qquad
\sum_{m=1}^{M}w_m=1.
$$

最终分类规则为：

$$
\widehat{y}
=
\mathbf{1}
\left\{
p_{\mathrm{soft}}(x)
\ge \tau
\right\}.
$$

本项目锁定近似权重为：

$$
w_{\mathrm{M1}}\approx0.80,
\qquad
w_{\mathrm{M2}}\approx0.15,
\qquad
w_{\mathrm{M4}}\approx0.05.
$$

分类阈值为：

$$
\tau=0.5.
$$

对应最终验证准确率约为：

$$
\mathrm{Accuracy}=0.8520.
$$

## F.2 代码

源文件：`src/tasks/task3/fusion.py`

```python
def soft_blend_search(
    model_p1,
    y,
    step=0.1,
    max_models=5,
):
    """model_p1: {name: p1向量}；在 OOF 上搜索融合权重。"""
    names = list(model_p1.keys())[:max_models]

    best = {
        "accuracy": -1.0,
        "weights": {},
        "threshold": 0.5,
    }

    best_p = model_p1[names[0]].copy()

    p_eq = np.column_stack(
        [model_p1[name] for name in names]
    ).mean(axis=1)

    acc_eq = float(
        (
            (p_eq >= 0.5).astype(int)
            == y
        ).mean()
    )

    if acc_eq > best["accuracy"]:
        best = {
            "accuracy": acc_eq,
            "weights": {
                name: 1.0 / len(names)
                for name in names
            },
            "threshold": 0.5,
        }
        best_p = p_eq

    for i, a in enumerate(names[:3]):
        for b in names[i + 1:4]:
            for wa in np.round(
                np.arange(
                    0.0,
                    1.0 + 1e-12,
                    step,
                ),
                10,
            ):
                p = (
                    wa * model_p1[a]
                    + (1.0 - wa) * model_p1[b]
                )

                acc = float(
                    (
                        (p >= 0.5).astype(int)
                        == y
                    ).mean()
                )

                if acc > best["accuracy"]:
                    best = {
                        "accuracy": acc,
                        "weights": {
                            a: float(wa),
                            b: float(1.0 - wa),
                        },
                        "threshold": 0.5,
                    }
                    best_p = p

    return best, best_p
```

# 粘贴时的排版提示

1. 附录代码使用等宽字体；
2. 公式使用 `$...$` 表示行内公式，使用 `$$...$$` 表示独立公式；
3. 多行公式使用 `aligned` 环境，并用 `\\` 换行；
4. 先写公式，再给出实现代码；
5. 不要整段粘贴 `pipeline.py`，只保留算法核心；
6. 任务二建议保留附录 E，避免审稿人误以为“没有建模”，并强调这是有统计证据支持的 Bayes 决策。
