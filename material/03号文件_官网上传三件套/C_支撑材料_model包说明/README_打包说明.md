# 支撑材料（model.zip）打包说明

## 上传文件名

`B` + 队伍编号 + `model.zip`  
例：`BDATA2600123model.zip`

## 建议操作（Windows）

1. 打开文件夹：`material/01号文件_比赛提交材料/`
2. 确认其中已有：
   - `Introduction.pdf`
   - `公共源代码/`
   - `任务一_*` / `任务二_*` / `任务三_*`（含模型与源码）
   - `DATA26XXXXXX_AI使用说明.pdf`（请改名为 `真实编号 AI使用说明.pdf`）
3. 全选上述内容 → 压缩为 zip  
4. 将 zip 重命名为 `B真实编号model.zip` 后上传官网

## 最低必备（赛方）

1. 训练好的模型文件  
2. 源代码  
3. Introduction.pdf（设计思路 / 环境 / 调用方式）  
4. （使用 AI 时）`队伍编号 AI使用说明.pdf`
