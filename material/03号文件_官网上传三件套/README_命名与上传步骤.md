# 官网上传步骤与命名（题号 B）

## 一、分别上传三项（不要合成一个文件上传官网）

1. **参赛论文**（仅 PDF）  
   - 命名：`B` + 队伍编号 + `.pdf`  
   - 例：`BDATA2600123.pdf`  
   - 要求：第一页为摘要专用页；第二页目录；正文起编页码；页眉含 Team# 与页码；**论文内不得附承诺书**；正文建议 ≤30 页，附录不限。

2. **承诺书**  
   - 命名：`B` + 队伍编号 + `cns` + `.pdf/.jpg/.png`  
   - 例：`BDATA2600123cns.pdf`  
   - 打印签名/电子签名后拍照或扫描；**单独上传**。

3. **支撑材料（模型预测结果）**  
   - 命名：`B` + 队伍编号 + `model.zip`（或 rar）  
   - 例：`BDATA2600123model.zip`  
   - zip 内至少包含：训练好的模型、源代码、Introduction.pdf，以及（若使用AI）`队伍编号 AI使用说明.pdf`。

## 二、推荐 zip 内部结构（支撑材料）

把 `01号文件_比赛提交材料` 的内容按下列结构打进 zip（可直接以该文件夹为根）：

```
Introduction.pdf
公共源代码/
任务一_EV采用意愿/
任务二_续航焦虑二分类/
任务三_支付意愿二分类/
总成绩metrics/
DATA26XXXXXX AI使用说明.pdf
```

说明：预测结果 CSV、建模报告、metrics 一并放入有利于复查，不违背「模型+源码+Introduction」最低要求。

## 三、提交注意

- 官网显示「已提交」才算成功；可重复提交，以最后一次为准。  
- 修改时先删旧文件再传新文件。  
- 备用邮箱通道与官网**二选一**，勿重复。
