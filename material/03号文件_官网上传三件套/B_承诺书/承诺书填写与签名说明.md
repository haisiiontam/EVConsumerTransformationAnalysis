# 承诺书填写与签名说明

## 文件

- 空白模板：`承诺书空白模板.docx`（赛方原件，请勿改动版式文字）
- 提交命名：`B` + 队伍编号 + `cns` + `.pdf/.jpg/.png`  
  例：`BDATA2600123cns.pdf`

## 必填项

1. 题号：填写 **B**（本队使用 dataSetB）  
2. 报名参赛队号：填写真实 `DATA26xxxxxx`  
3. 队员签名 1/2/3（无打印条件可由队长代签，含跨校）  
4. 指导教师签名（按学校要求）  
5. 日期

## 提交形式

手写签名后拍照/扫描为 PDF 或 JPG/PNG，**单独上传**，不要放进论文 PDF。

## 注意

论文电子版中**不得出现**承诺书页。
