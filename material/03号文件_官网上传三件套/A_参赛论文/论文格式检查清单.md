# 论文格式检查清单（对照赛方规范）

- [ ] 文件名：`B` + 队伍编号 + `.pdf`
- [ ] 第 1 页：摘要专用页（题目+摘要+关键词），不超过一页
- [ ] 第 2 页：目录
- [ ] 正文起编页码；页脚中部阿拉伯数字
- [ ] 每页页眉：`Team# DATA26XXXXXX page k of n`
- [ ] 中文；正文建议 ≤30 页；附录不限
- [ ] 参考文献格式符合规范；正文引用处有 [序号]
- [ ] 附录含软件名称与源程序说明（完整源码放支撑材料 zip）
- [ ] **论文中不含承诺书**
- [ ] 参考文献后附「AI工具使用声明」
- [ ] 参考文献列出所用 AI 工具条目
- [ ] 队伍编号与报名系统完全一致
